PROJECT MISSION

从“看见异常”到“提前行动”

设备维护不应发生在故障之后。本项目将传感器的功率、信号强度、时间戳等运行信息转化为可执行洞察，帮助使用者更早发现风险、理解趋势，并给出维护建议。它既适合在缺少真实设备数据时快速验证算法，也能作为接入实时数据后的预测性维护原型基础。

HOW IT WORKS

数据流动，决策发生

  1. 采集或生成数据训练集、测试集、人工干预数据与时间序列数据。
  2. 清洗与特征处理处理时间字段、缺失值，并完成标准化或归一化。
  3. 识别异常与预测趋势使用 Isolation Forest 发现异常，借助 Prophet 预测未来 24 小时趋势。
  4. 输出维护建议通过 XGBoost 将异常信号转化为清晰的维护判断与评估结果。

CORE MODULES

四个模块，一条智能闭环

01

模拟数据生成

构造训练、测试、人工干预与时间序列数据，使模型原型能在没有真实设备数据时快速验证。

sensor_ID · power · signal_strength · timestamp
02

故障检测

使用 Isolation Forest 识别偏离正常工作区间的设备，并输出疑似异常传感器清单。

StandardScaler · IsolationForest · Plotly
03

维护决策

以已标注故障样本训练 XGBoost，将异常信号转化为“是否需要维护”的可执行建议。

XGBoost · Accuracy · Feature Importance
04

趋势预测

借助 Prophet 预测未来 24 小时的功率或信号强度，并呈现预测区间与不确定性。

Prophet · 24h Forecast · Confidence Interval
